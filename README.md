# 사케 카드

사케를 찾아보고, 마신 술을 카드로 모으고, 맛 6축으로 테이스팅 노트를 남기는 앱.

**https://kamjjie0421-png.github.io/sake-card-dex/**

## 쓰는 법

1. **도감**에서 사케를 검색합니다 (1,355종). 없으면 **직접 추가**할 수 있습니다
2. 카드를 열어 **「마셨어요」**를 누르면 내 카드가 됩니다
3. 맛 6축(華やか·芳醇·重厚·穏やか·ドライ·軽快)의 점을 끌어 **내가 느낀 값**을 그립니다
4. 회색 점선은 데이터 평균 — 두 선이 벌어진 만큼이 내 감각의 기록입니다
5. 맛·향 태그, 마신 온도, 한 줄 메모를 남깁니다

같은 술을 다시 마시면 **덮어쓰지 않고 새 기록으로 쌓입니다.** 지난 기록을 탭하면
그때 그린 값을 불러와 비교할 수 있습니다.

## 저장

기록은 **이 브라우저에만** 저장되며 서버로 전송하지 않습니다.
「내 기록 → 내보내기」로 백업하고, 다른 기기에서 「가져오기」로 복원합니다.

홈 화면에 추가하면 앱처럼 열리고 오프라인에서도 동작합니다.
