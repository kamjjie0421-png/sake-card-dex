# 사케 카드

마신 사케를 카드로 모으고, 맛을 6축으로 그려 기록하는 웹앱.

**→ https://kamjjie0421-png.github.io/sake-card-dex/**

브라우저에서 바로 열리고, 「홈 화면에 추가」하면 앱처럼 전체화면으로 뜬다.
설치할 것도, 가입할 것도 없다.

## 무엇을 하나

- **도감** — 사케 1,354종을 이름·양조장·지역으로 찾는다. 한국어로도 검색된다(「아키타」).
- **카드** — 마신 술을 카드로 담는다. 같은 브랜드라도 병마다 다른 술이라 병 단위로 남는다.
- **테이스팅 노트** — 맛 6축(화려함·풍부함·묵직함·부드러움·드라이·가벼움)을 손으로 끌어
  그리고, 도감 평균과 겹쳐 본다. 같은 술을 다시 마시면 덮어쓰지 않고 기록이 쌓인다.
- **지역 지도** — 일본 47개 도도부현 중 몇 곳을 마셨는지 센다.
- **이미지로 저장** — 카드를 1080×1350 그림으로 뽑는다.

## 기록은 어디에 남나

**이 브라우저에만.** 서버로 보내지 않고, 계정도 없다. 기기를 바꾸거나 브라우저를 지우면
사라지므로 「내 기록 → 내보내기」로 JSON 백업을 받아 두면 된다. 같은 파일을 「가져오기」하면
다른 기기에서 그대로 복원된다.

## 데이터

브랜드·양조장·맛 6축은 [さけのわデータ](https://sakenowa.com)를 가공해 사용한다.

## 만든 사람

박세정 — 사케를 마시고 기록하다가, 기록할 자리가 마땅치 않아 만들었다.
